# AI-Assisted Engineering Workflows

Smart, battle-tested techniques and prompts to boost a developer's daily work with AI.

These aren't theory — they're the patterns I actually use, refined in practice. The flagship one has been **presented to 400+ engineers.**

## What's inside

### 🧩 [Research → Plan → Implement](workflows/research-plan-implement%20developer's%20workflow/) — flagship
Solve complex implementation problems with an AI agent **without losing the context that got you there.** One curated markdown file as the agent's working memory; iterate freely, pollution-free.

### 📚 [AI-Led Learning](workflows/ai-led-learning/)
Turn scattered AI conversations into a durable, versioned personal knowledge base — four prompts that collect, enhance, and format what you learn into clean markdown.

### 🧪 [AI-Assisted Testing](techniques/ai-assisted-testing/)
Reduce the effort of writing and maintaining tests — generate from implementation or from code changes, and repair failing ones.

### ✍️ [Prompt Engineering](techniques/prompt-engineering/)
Worked examples showing the principles of effective prompt construction, and *why* they work.
